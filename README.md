## 使用方法

1. 点击上面的飞书文档入口。
2. 使用 `Ctrl + F` 搜索年份、科目、考试类型或省份，例如「申论」「综应A」「广东」。
3. 找到需要的资料后，打开对应网盘链接并保存。
4. 可以先查看国省考资料合集和全家桶笔记，再按自己的备考进度补充专项。
